# Image Display Extension

チャットのメッセージ本文に含まれるキーワードに応じて、対応する画像を表示する
ドラッグ&リサイズ可能なウインドウをSillyTavern画面上に追加します。

## 主な機能

- ユーザー発言／AI発言のどちらを監視するか切り替え可能（画面左下「UT」「AI」ボタン）
- AIメッセージのストリーミング生成中は、1秒間テキストが変化しなくなるまで画像更新を
  遅延させ、生成途中の文章での誤爆を防止
- キーワード条件は `and` / `or` / 括弧によるグループ化に対応
- 一致した画像が配列の場合はランダムに1つ選択（複数バリエーション対応）
- 通常表示／最大化／左半分表示の3モード、背景色変更、位置・サイズの保存

## データソース

キーワードと画像の対応表は、`SillyTavern.getContext()`経由でキャラクターカードの
拡張データを見るか、無ければ `addchara/<キャラ名>/<キャラ名>_ext.json` をfetchします。
このJSONは `stj_editor` 拡張機能で作成・出力できます。

## インストール方法

1. SillyTavernの拡張機能パネルを開く
2. 「拡張機能をインストール」をクリック
3. このリポジトリのURLを貼り付けて保存

## 前提となる手動セットアップ

`addchara/default.png`（フォールバック用デフォルト画像）を、SillyTavernサーバーの
`public/addchara/default.png` に一度だけ手動で配置してください。
拡張機能の自動更新ではこのアセットは配置されません。

## 関連拡張機能

- `stj_editor` — このJSONを作成・出力する側の拡張機能
- `right_nav_kai` — 同じJSONの`thumbnail`のみを読み込む拡張機能
